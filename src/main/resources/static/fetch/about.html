About this app

Plant Tracker demo. The same database and service layer power two front ends: a JSON API for programs, and these HTML pages for people.

How a page request flows

  1. The browser loads a static HTML page, for example /fetch/details.html?id=3.
  2. Vanilla JavaScript uses fetch to request plant data from /api/plants/3.
  3. The REST controller asks the service for data and returns JSON.
  4. The browser uses JavaScript to display the response in the page.
